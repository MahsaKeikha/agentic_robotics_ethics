# F80 Agentic Robotics Ethics

Standalone multi-agent reference implementation for robotics ethics analysis, stakeholder impact, rights and agency review, governance, transparency, and accountability.

Agents: [Stakeholder Impact](AGENTS/stakeholder_impact_agent.py), [Human Agency](AGENTS/human_agency_agent.py), [Fairness Review](AGENTS/fairness_review_agent.py), [Transparency](AGENTS/transparency_agent.py), [Governance](AGENTS/governance_agent.py), [Accountability](AGENTS/accountability_agent.py).

Tools are in `TOOLS/`, skills in `SKILLS/`, with orchestration, memory, state, schemas, prompts, config, safety, observability, evals, benchmarks, examples, tests, docs, and CI.

This project supports structured analysis and review. It does not make binding policy decisions or control robots.
